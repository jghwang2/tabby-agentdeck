# 계정 관리 및 전환 실패 수정 검증

## 수정

- 추가 폼에 표시 이름(선택)을 제공하고, 목록에 이름과 이메일을 함께 표시한다.
- 전체 이메일이 아닌 항목은 전환을 차단하며, 새 항목에도 전체 이메일을 요구한다.
- 목록에서 삭제하면 해당 등록 항목과 그 안의 저장 인증정보가 제거된다. 실행 중인 CLI와 계정별 네이티브 인증 폴더는 유지한다.
- Codex 인증 확인에서 `account/read`의 강제 토큰 갱신을 제거한다. 실제 등록 계정 중 하나가 강제 갱신을 사용하면 인증 실패로 판정됐고, 일반 확인으로 바꾸면 두 계정 모두 통과했다.
