# 업데이트 검사 변경 (2026-10-01)

- 앱 준비 직후 검사한다. 기존 8초 지연과 마지막 검사 후 6시간 제한은 서비스에서 사용하지 않는다.
- 자동 검사는 AgentDeck 기동 시 한 번만 수행한다. 창 활성화로 다시 검사하지 않는다. 조회/안내/설치가 진행 중이면 같은 요청을 공유한다.
- 같은 버전 안내는 창 인스턴스마다 한 번만 표시한다. 새 버전과 명시적 강제 검사는 안내할 수 있다.
- 조회 실패는 성공 시각으로 기록하지 않으며 다음 검사에서 바로 재시도한다. 설치 실패 역시 다음 안내를 허용한다.
- 자동 업데이트 비활성화, 버전 건너뛰기, 개발 설치 보호는 유지한다.
