# 계정 전환·추가 검증 — 2026-09-21

## 변경

- 계정 선택은 현재 탭의 CLI를 재시작하고 동일 대화를 재개한다. 새 탭·대화 분기는 만들지 않는다.
- 현재 계정 재선택은 아무 작업 없이 닫는다. 탭이 닫혔으면 전환을 중단한다.
- 계정 선택창의 `+`에서 이메일·비밀번호를 입력하고 로컬 평문으로 저장한다.
- 평문 저장 안내·입력 항목·오류 문구는 앱 설정 언어를 따른다. 22개 언어의 키·자리표시자를 검증했다.
- 중복 계정·빈 입력·잘못된 기존 JSON은 저장하지 않는다. 기존 계정·인증정보를 보존한다.

## 계정정보 유출 방지

- 기존 계정 JSON의 값 포함 차단에 더해 커밋 대상 전체 파일·파일명을 검사한다.
- 모든 로컬 등록 계정의 ID·비밀번호·암호화 인증값과 계정별/기본 CLI의 인증 토큰을 실행 시 읽는다. 실계정 값을 검사 코드에 넣지 않는다.
- 평문·JSON 이스케이프·URL 인코딩·Base64·UTF-16 형태를 검사하고, 일치 값은 출력하지 않는다.
- `test/accountSecrets.cjs`: 네 계정의 가상 값·토큰을 문서에 스테이징하면 차단됨을 실제 임시 Git 저장소에서 확인. 작업 파일만 지워도 스테이징된 값은 차단하며, 로컬 검사 원본을 읽지 못하면 실패한다.
- 실계정 파일·계정 홈·화면 원문·테스트 로그는 저장소 밖에 유지한다.
