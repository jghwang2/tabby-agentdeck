# 창 이동과 작업 루트 프로필

Windows의 `appearance.frame: thin`에서 AgentDeck이 순정 탭바를 숨기면 원래 창 이동 영역도 사라진다. 상단 32px를 제목 표시줄로 확보하고 `.window`를 그 아래에 배치한다. 제목 표시줄은 Electron의 네이티브 드래그 영역이므로 관리자 권한이나 별도 이동 프로세스가 필요 없다. 창 제어 버튼은 Windows의 원래 버튼을 사용한다. AgentDeck을 끄거나 전체 화면으로 전환하면 추가 제목 표시줄은 숨긴다.

기존 단일 작업 루트(`agentdeck:root`)는 유지한다. 설정의 **추가 작업 루트 프로필**에서 이름·폴더·실행 명령을 저장하면 별도의 안정된 ID로 Tabby 로컬 프로필을 등록한다. 빈 폴더는 실행 목록에 등록하지 않는다. 기존 프로필의 셸 인자와 환경변수는 편집 시 유지한다. 삭제는 해당 작업 루트 프로필만 회수하며, 실행 중인 탭은 닫지 않는다.

**+ 새 탭 / Ctrl+T**는 작업 루트가 하나이면 그 프로필로 바로 연다. 두 개 이상일 때만 이름·경로를 선택창에 표시한다. 취소하면 새 탭을 만들지 않는다. 작업 루트가 없으면 기존 기본 프로필로 연다. 선택창이 떠 있는 동안 중복 생성 요청을 막으며, 선택·취소 후 예약을 해제한다.
