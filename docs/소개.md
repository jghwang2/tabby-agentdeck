# tabby-agentdeck 소개

**Claude Code·Codex 같은 AI 에이전트 CLI 를 여러 탭에 띄워 놓고 쓰는 사람**을 위한 Tabby 터미널 플러그인.

어느 에이전트가 돌고 있고 어느 쪽이 내 승인을 기다리는지, 탭을 옮겨 다니지 않고 한눈에 본다.
에이전트가 만든 문서·그림은 터미널 옆 미리보기 패널에서 바로 확인한다.
거기에 에이전트 CLI 가 터미널에서 겪는 고질적인 문제들(이미지 붙여넣기, 줄바꿈 키, pty 폭 어긋남, 2중 붙여넣기)을 같이 손봐 뒀다.

```
┌────────────────────┬──────────────────┬──────────────────┐
│                    │ note.md   ＋ ⟳ ✕ │ AGENT DECK    4  │
│  터미널 (4:3 기준)   ├──────────────────┼──────────────────┤
│                    │ note.md  shot.png│ ● 진행중  리팩터링 │
│  Tabby 순정 탭바는   ├──────────────────┤ ⏸ 승인대기 재빌드 │
│  숨김               │ # 제목            │ ✔ 완료   테스트   │
│                    │ 본문이 그려진다     │ ○ 대기            │
│                    │ [그림]            ├──────────────────┤
│                    │ 742 B · 방금      │ + 새 탭 │ 설정    │
└────────────────────┴──────────────────┴──────────────────┘
      터미널              미리보기 패널        세션 목록
```

## 1. 에이전트 현황판 (사이드바)

- **작업 상태 6종** — 진행중 / 승인대기 / 한도 도달 / 완료 / 오류 / 대기 를 색·배지·경과시간으로 표시. 한도 도달은 Claude Code 사용량 한도에 걸려 멈춘 세션으로, 리셋 시각을 함께 보여준다.
- **탭 관리** — 클릭=선택, `×`=닫기, 더블클릭=작업 이름 편집, 우클릭=상태 직접 지정.
- **가려져 있어도 갱신** — Chromium 은 창이 가려지면 렌더링을 분당 1회까지 스로틀한다. `keepRenderingWhenHidden` 이 이걸 꺼서 "다 끝났는데 화면만 옛 상태" 를 막는다.

## 2. 작업 이름과 상태를 아는 법

**둘 다 플러그인 코드만으로 채운다 - 설정도, 에이전트의 협조도 필요 없다.**

| 무엇 | 어떻게 |
|---|---|
| **작업 이름** | Enter 로 프롬프트를 보내는 순간 화면의 입력창(`> ...`)을 읽어 40자로 잘라 쓴다 |
| **상태** | PTY 출력이 흐르면 진행중, 2.5초 조용하면 대기. `Do you want to`·`(y/n)` 패턴이면 승인대기 |

작업 이름을 **키 입력이 아니라 화면에서** 읽는 이유는, 붙여넣기·↑ 히스토리·자동완성·IME 로 들어온 글자가
키 이벤트로는 안 오거나 원문과 다르기 때문이다. 화면에 그려진 것이 곧 보낼 내용이다.
줄바꿈(Shift/Ctrl+Enter)과 IME 조합 확정 Enter 는 전송이 아니므로 잡지 않는다.

탭 제목을 쓰지 않는 이유 - Claude Code 는 세션의 첫 작업을 요약해 콘솔 제목에 한 번 박고 그 뒤로 갱신하지
않는다. 제목만 보여주면 사이드바가 옛 작업 이름에 박혀 있게 된다.

직접 지정하고 싶으면 사이드바 우클릭(상태) · 더블클릭(이름). 셸 스크립트 안에서라면 콘솔 제목을
`[AD:<status>] <라벨>` 로 바꿔도 된다 - 이렇게 지정한 값은 고정되어 자동 감지가 덮어쓰지 않는다.

## 3. 결과물 미리보기 패널

에이전트가 만든 것이 문서(md)나 그림이면 터미널 안에서는 확인이 안 된다. 탐색기로 나가서 여는 그 왕복이
"결과물을 안 보고 넘어가는" 이유였다. 터미널 옆에 붙는 패널이 그 자리를 메운다 — 사이드바 **▤** 로 여닫는다.

- **md** 는 제목·표·목록·체크박스·인용·코드·문서 안 이미지까지 그려서 보여준다.
- **이미지**(png/jpg/gif/webp/svg…)는 원본 크기로, **csv/tsv** 는 표로, **코드·텍스트**는 줄 번호를 붙여 보여준다.
- 열어 둔 파일이 바뀌면 **스스로 다시 읽는다** — 에이전트가 문서를 고치는 동안 옆에서 따라간다.
- 같은 패널의 **`변경` 탭**은 작업트리의 `git diff` 를 보여준다 — 파일 목록 · `+N -M` · 줄번호 붙은 유니파이드 diff. 근거가 git 이라 누가 고쳤는지와 무관하게 성립한다.

**어느 에이전트를 쓰든 똑같이 동작한다.** 파일을 고르는 근거가 특정 CLI 의 기능이 아니라
"만진 파일 경로를 화면에 찍는다" 는 세 CLI 의 공통 습성이어서다 — `Edited src/hero.tsx`,
`Wrote D:\a\b.md`, `Read build.py` 를 주워 최근 목록에 쌓는다(탭마다 따로). 끌어다 놓기와
경로 직접 입력(**＋**)도 된다. 문서 안의 원문 HTML 은 태그로 만들지 않고 글자로만 보여준다.

패널을 열면 4:3 이 완화되고 터미널이 그만큼 좁아진다(사이드바는 줄지 않는다).
울트라와이드에서는 열어도 4:3 이 그대로 유지된다.

## 4. 4:3 고정 레이아웃

창 높이에서 폭을 역산해 터미널 뷰포트를 4:3 으로 잡고, 남는 가로 공간을 사이드바로 쓴다.
와이드 모니터에서 터미널이 쓸데없이 넓어지는 걸 막고 그 공간을 현황판으로 돌린다.

곁들여 해결한 것 — CSS 로만 폭을 바꾸면 xterm 은 넓은데 pty 는 옛 폭이라 입력창이 깨진다.
`fitAddon.fit()` + `session.resize()` 로 pty 에 직접 내려보내고, 탭당 한 번 폭을 흔들어(`redrawKickMs`) TUI 첫 화면 잔상까지 지운다.

## 5. 입력 보정 — 윈도우 관습 그대로

에이전트 CLI 는 터미널 위에서 도는 TUI 라 윈도우 앱의 키 관습이 그냥은 안 먹는다.
`Shift+Enter` 로 줄바꿈하고 `Ctrl+V` 로 붙여넣는 — **윈도우 사용자가 당연히 기대하는 동작**을 그대로 쓰게 맞췄다.

| 키 | 기대 | 실제로 하는 일 |
|---|---|---|
| `Shift+Enter` / `Ctrl+Enter` | 전송 말고 줄바꿈 | 터미널의 Enter 는 `0x0D`(전송)뿐이라 줄바꿈이 없다. Claude Code 가 줄바꿈으로 받는 `0x0A` 를 대신 보낸다 |
| `Ctrl+V` | 텍스트든 이미지든 붙여넣기 | 클립보드를 미리 보고 갈라 보낸다 — 텍스트면 평소대로, **이미지면** 앱을 판별해 Claude Code 엔 `ESC v`, Codex 엔 `0x16` |
| 우클릭 | 선택 있으면 복사, 없으면 붙여넣기 | 윈도우 콘솔 관습 그대로. 250ms 이상 누르면 컨텍스트 메뉴 |

**이미지 붙여넣기가 왜 특별한가** — 터미널의 붙여넣기는 "클립보드 *텍스트* 를 PTY 에 써넣는" 동작이라
바이트 스트림에 이미지를 실을 방법이 없다. 그래서 순정 터미널에서 스크린샷을 `Ctrl+V` 하면 조용히 사라진다.
에이전트 CLI 는 자기가 OS 클립보드를 직접 읽어서 이 문제를 푸는데, 그 "지금 읽어라" 신호 키가 앱마다 다르다.
사용자가 그걸 구분할 이유는 없으니 플러그인이 대신 갈라 보낸다 — **키는 `Ctrl+V` 하나로 통일**.

**2중 붙여넣기 차단** — Tabby 는 한 번의 `Ctrl+V`/우클릭을 여러 경로로 밀어 넣어 두 번 붙는 일이 있다.
플러그인이 document **캡처 단계**에서 한 번만 받아 뒤의 경로를 통째로 끊는다.

## 6. 그 외

- **기본 프로필** — 새 탭을 항상 지정한 작업 루트에서 연다.
- **반투명 배경** — 터미널/사이드바 불투명도(기본 75%)를 조절해 배경 이미지가 비치게 한다.
- 모든 동작은 `config.yaml` 의 `agentDeck` 아래에서 끌 수 있다. 자세한 키 목록은 [전체 레퍼런스](REFERENCE.ko.md#설정).

## 설치

```powershell
npm install
npm run build
powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1
```

플러그인 폴더에 junction 을 걸어두므로, 이후엔 `npm run build` 만 하면 재시작 없이 반영된다
(개발자 옵션이 창만 리로드한다 — 탭·세션 유지).
