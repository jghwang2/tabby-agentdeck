# 훅 등록 갱신

AgentDeck 시작 시 기본 Claude/Codex 홈과 저장 계정 홈에서 구형 AgentDeck PowerShell 전달기 등록을 찾는다. 발견하면 기존 설치 안내를 닫았던 사용자에게도 **기존 훅 갱신** 안내를 표시한다. 단순히 앱 버전이 바뀔 때마다 표시하지는 않는다.

- **갱신한다**: 설정 원문을 `.agentdeck-hook-upgrade-backup`에 백업하고 AgentDeck 전달기 명령만 Node 직접 실행으로 교체한다. 사용자 훅, matcher, timeout, async, statusLine과 다른 설정은 보존한다.
- **나중에**: 설정을 쓰지 않는다. 다음 앱 시작 시 다시 확인한다.
- 현재 방식이면 안내하지 않는다. 훅이 없는 CLI에 자동으로 새 훅을 설치하지 않는다.
- 별도 `claude-compat` 훅처럼 이름만 같은 다른 연동은 교체하지 않는다. 사용자 정의 명령 체인도 그대로 둔다.
- 안내가 열린 동안 설정이 바뀌면 저장하지 않고 오류를 알린다. Codex의 신뢰 상태는 수정하지 않는다. 실행 중인 CLI는 훅 재로드나 재시작이 필요할 수 있다.

이번 마이그레이션은 PowerShell → Node 직접 실행에 한정된다. 앞으로 등록 구조가 다시 바뀌면 해당 변경을 판별하고 옮기는 마이그레이션을 추가해야 한다. 등록 명령과 경로가 그대로인 훅 구현 변경은 패키지 파일 업데이트로 반영된다.

`node test/hookUpgrade.cjs`는 기본 교체, 보존, 멱등성, 설정 변경 충돌과 손상 JSON을 검사한다. `tools/probe-hook-upgrade.js`는 `usage-refresh-ui` 전용 격리 앱에서 거절·실제 갱신 팝업·백업·재안내 방지를 검사한다. 실사용 설정 대상으로 이 프로브를 실행하지 않는다.
