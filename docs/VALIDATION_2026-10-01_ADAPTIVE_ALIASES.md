# 프로젝트별 자동 별명

고정 게임 분류 대신 프로젝트 경로에서 이름을 발견한다. 프로젝트 루트 캐시를
활용하며 렌더링 중 파일 읽기나 외부 모델 호출을 추가하지 않는다.

- 특정 프로젝트명 변환을 내장하지 않으며, 경로 또는 제목의 Global/글로벌,
  China/CN/중국 구분을 새 별명에 반영한다.
- 처음 보는 프로젝트는 경로의 프로젝트 폴더명을 사용한다.
- `샘플 프로젝트` 또는 `프로젝트: 샘플`처럼 명시된 제목은
  해당 경로의 이름으로 저장한다. 경로에서 얻은 이름만 보강하며 이미 명시적으로
  학습한 이름과 충돌하는 제목은 덮어쓰지 않는다.
- 기존 별명은 그대로 유지한다. 학습 결과는 새 별명에만 적용한다.
- 프로젝트 단서가 없는 기본 셸은 별명 준비 중으로 표시하고 작업 단서가
  생기면 이름을 확정한다. 격리 앱에서 대기→확정 경로를 확인했다.
- 프로젝트명·경로 매핑은 사용자 로컬 설정에만 저장한다. 소스·테스트에는
  가상 프로젝트만 사용하며 로컬 실측 파일은 Git에서 제외한다.
- 프롬프트 훅과 통신 문서는 사용자별 별명을 최신 스냅샷에서 실제 세션 ID로
  해석하도록 안내한다. 예시 이름이나 탭 순서로 주소를 추측하지 않는다.
- 임의 약어를 해석하거나 자유로운 대화 전체에서 의미를 추론하는 AI 학습은 아니다.
  명확한 단서가 없으면 프로젝트 폴더명을 사용한다.

검증: 타입 검사, 세션 테스트 통과. 격리 앱에서 지역 구분, 미등록 프로젝트,
명시적 이름 학습, 기존 별명 고정, 후속 탭 적용, 저장, 상태 줄 배치 통과.
리로드 후 별명·제목·PTY 유지 통과.
증거: `.tmp/adaptive-alias-ui.json`, `.tmp/adaptive-alias-reload-after.json`.

최종 회귀: 179항목 중 172 PASS / 0 FAIL / 7 SKIP. 전체 npm 테스트 포함.

통신 훅도 검증한 동일 파일로 설치했다. 실사용 리로드 시점의 터미널 3개 모두
PTY ID와 기존 별명이 유지됐다. 리로드 직전 DOM에 남은 설정 행의 빈 별명은
비교에서 제외했다. 소스 추가분과 새 파일에서 실제 프로젝트명 노출 검사 통과.
커밋·푸시는 수행하지 않았다.
