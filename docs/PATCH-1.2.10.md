# 1.2.10 패치 준비 (2026-10-22)

공개 버전은 npm 조회 및 원격 태그 기준 1.2.9다. 1.2.10은 준비 버전이며 공개 배포하지 않았다.

## 미반영 변경 점검

- 원격 갱신 후 모든 로컬 브랜치·작업 폴더를 확인했다. 점검 시점에 어떤 원격에도 없는 로컬 커밋은 없었다.
- `8ad5001`은 작업 브랜치에는 올라갔지만 `origin/main`과 `v1.2.9`에는 없는 변경이다. 빈 메시지함 문맥 축소·한글 출력 보존·설정창 반복 훅 조회 제거가 이번 패치에 포함된다.
- 이번 미커밋 변경인 통신 ON/OFF, 필요할 때 문맥 조회, 수신기 처리 이전과 관련 검사를 함께 포함한다.
- 기존 휠·한글 입력·리로드 상태·메모리 정리·서브에이전트 활동 수정은 1.2.9에 반영됐다. 남은 작업 폴더의 차이는 이미 반영된 사본, 이후 수신기로 이동하거나 갱신한 구현, 검사 보완 및 임시 로그다. 추가 제품 수정 누락은 발견하지 못했다. 오래된 작업 폴더는 보존했다.
- 외부 경로 `E:/Tools/CodexMarketplaceGuard/guard.py`의 반복 알림 제거는 로컬 도구 변경으로 이 npm 패키지에 포함되지 않는다.

## 공개 배포 시

`CHANGELOG.md`의 `Unreleased`를 실제 배포 날짜로 확정하고 패치노트 생성 검사를 수행한다. 준비 중인 현재 버전만 태그 검사에서 예외이며, 날짜가 확정되면 기존 태그 필수 검사가 적용된다. 배포 태그 푸시는 npm 자동 공개를 실행하므로 준비 단계에서 수행하지 않는다. 이번 버전 준비로 실사용 설치본을 다시 교체하지 않았다.
