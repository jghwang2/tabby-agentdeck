# 지난 대화 식별자 검색

지난 세션 서랍의 검색창에서 함수명, 오류코드, 파일명 등 문자열을 찾는다. 대소문자를 구분하지 않는 부분 일치이며 정규식이나 의미 검색은 아니다. 제목·프로젝트 경로·세션 ID도 검색한다. 결과의 숫자는 일치한 질문/답변 메시지 수다.

- Claude: `CLAUDE_CONFIG_DIR/projects` 또는 `~/.claude/projects`의 세션 JSONL.
- Codex: `CODEX_HOME/sessions` 또는 `~/.codex/sessions`의 세션 JSONL.
- 질문과 답변의 텍스트만 검색한다. 도구 호출·도구 결과·추론·시스템/개발자 메시지·서브에이전트 기록은 제외한다.
- 최근 목록의 표시 개수/기간 제한과 관계없이 발견한 기록 전체를 검색한다.
- 결과 선택은 읽기 전용 미리보기다. 앞뒤 대화를 더 읽을 수 있으며, 명시적으로 `이어서 대화`를 누르면 기존 이어받기 동작을 사용한다. 이미 열린 세션이면 그 탭으로 이동한다.

별도 Node.js 프로세스가 파일을 읽고 로컬 압축 캐시를 만든다. Tabby의 렌더러에서는 Node Worker를 지원하지 않으므로, PATH에 설치된 Node.js를 셸 없이 실행한다. 캐시는 `%LOCALAPPDATA%/tabby-agentdeck/history-search`에 저장하며 파일 크기·수정 시간·생성 시간 변경 시 다시 읽는다. 캐시에는 대화 텍스트가 포함되며 삭제하면 다음 검색에서 재생성된다. 캐시를 삭제해도 원본 대화는 바뀌지 않는다. 네트워크 전송·임베딩·MCP 도구 등록은 없다.

현재 검색 대상은 위의 현재 설정된 두 기록 홈이다. 다른 계정의 별도 홈, Codex archived_sessions, 원본이 삭제된 대화는 검색하지 않는다. 새 검색은 진행 중인 검색을 취소하며, 깨진 JSONL 줄은 건너뛰고 읽지 못한 파일/불완전한 기록 수를 표시한다.
